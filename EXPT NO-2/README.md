
# Deep Learning Lab - Experiment 2

## Comparative Study of Activation Functions and Optimization Algorithms in Deep Learning

### Objective
This experiment compares the performance of different activation functions (Sigmoid, Tanh, and ReLU) and optimization algorithms (SGD, Momentum, RMSProp, and Adam) using an Artificial Neural Network (ANN) on the MNIST handwritten digit dataset.

### Software Requirements
- Python
- TensorFlow
- Google Colab
- NumPy
- Matplotlib

### Experiment Overview
- Visualized Sigmoid, Tanh, and ReLU activation functions.
- Compared activation functions using the same ANN architecture.
- Evaluated SGD, Momentum, RMSProp, and Adam optimizers.
- Plotted training/validation accuracy and loss.
- Managed the experiment using Google Colab, Google Drive, and GitHub.

### Dataset
- MNIST Handwritten Digits Dataset
